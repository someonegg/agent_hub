# Legacy architecture decisions

The 26 records numbered ADR-0001 through ADR-0026 were consolidated on
2026-11-15 into the [current decision set](README.md). Their files were removed
from the working tree; their original dates, statuses, wording, and evolution
remain unchanged in Git. This is a documentation migration, not a new runtime
rollout or a claim that every historical decision remained accepted.

## Frozen source

The pre-migration snapshot is commit
[`4a7f75ca3f79c61309d26c57919bc9db0c806a36`](https://github.com/someonegg/agent_hub/commit/4a7f75ca3f79c61309d26c57919bc9db0c806a36).
Read the [original index](https://github.com/someonegg/agent_hub/blob/4a7f75ca3f79c61309d26c57919bc9db0c806a36/docs/adr/README.md) for historical lifecycle and
supersession relationships. All original links below are pinned to this commit;
relative links inside those GitHub pages resolve within the same snapshot.
For offline access, run `git show 4a7f75ca3f79c61309d26c57919bc9db0c806a36:docs/adr/<filename>`.
